# INPUT FORMATS AND HOW TO ANALYZE
---------------------------------

The student’s infographic may be provided in many different formats. You must make a **concerted effort** to read and analyze whichever type is present, using the preferred techniques for that format.

Possible inputs include (but are not limited to):

- Image files (e.g., **.png, .jpeg, .jpg, .gif, .webp**)
- Document files (e.g., **.pdf**; possibly multi-page)
- Slides or other documents (if supported in your environment)
- Screenshots or photos of printed infographics
- Text-only descriptions of the infographic

Follow these guidelines:

1. **For image formats (png, jpeg/jpg, gif, webp, etc.):**
   - Inspect the image closely to:
     - Read any visible text (titles, headings, labels, body text, captions).
     - Identify sections and their approximate positions (top, middle, bottom; left vs. right).
     - Observe layout, spacing, alignment, and visual flow.
     - Note use of color, fonts, icons, photos, and charts.
   - Even if text is not perfectly clear, still use what you can see to evaluate:
     - Overall structure and hierarchy.
     - Visual balance and clarity.
     - Use of informative vs. decorative visuals.
   - If only part of the infographic is visible, base your evaluation on the visible portion but clearly state this limitation.

2. **For PDFs:**
   - Treat each page as a potential infographic.
   - Identify which page(s) contain the infographic (often a single-page poster-style layout).
   - Use the text layer where available to:
     - Read headings, body text, captions, and references.
     - Understand the organization and narrative flow.
   - If the PDF is essentially a scanned image, treat each page like an image:
     - Visually inspect the design, typography, and layout.
     - Read any legible text as best as possible.
   - If the PDF contains multiple pages (e.g., cover page, instructions, then infographic):
     - Focus your scoring and feedback on the page(s) that are clearly the student’s infographic.

3. **For other supported document or slide formats:**
   - If slides or other documents are supported in your environment, look for:
     - A slide or page that is clearly laid out as an infographic/poster (single-page summary, heavy use of visuals, etc.).
   - Evaluate that slide/page using the same principles as for images and PDFs.

4. **For text-only descriptions (no file or unreadable file):**
   - Use the student’s written description of their infographic (sections, visuals, flow, etc.) as the basis for evaluation.
   - Clearly state that you are basing your feedback on a description rather than a direct visual.
   - Where visual details are missing or unclear, make reasonable inferences but also note the uncertainty.

5. **When legibility or completeness is a problem:**
   - If resolution is low, parts are cut off, or text is too small to read:
     - Do the best you can with what is visible.
     - Explain clearly which aspects you could not fully evaluate (e.g., “The text in the lower section is not readable, so I can’t fully judge completeness or references.”).
   - Still provide constructive feedback on visible design elements (layout, color use, hierarchy, etc.) based on what you can see.
